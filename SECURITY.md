# Политика безопасности

Не публикуйте сведения об уязвимости, подписочные ссылки, VPN-ключи или конфигурации в открытом Issue.

Используйте [приватную форму GitHub Security Advisories](https://github.com/crxwov/deytt.connect/security/advisories/new). Укажите затронутую версию, Android-устройство и безопасные шаги воспроизведения. Не включайте данные аккаунтов и действующие секреты.

Публичные исправления и пользовательские изменения публикуются в [GitHub Releases](https://github.com/crxwov/deytt.connect/releases).
