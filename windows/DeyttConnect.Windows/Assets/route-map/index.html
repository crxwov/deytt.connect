система и запуск
запуск при старте windows автоматически запускать ./connect при входе пользователя в систему
автоподключение при старте устанавливать защищенное соединение сразу после запуска программы
сворачивать в системный трей при закрытии окна прятать приложение в трей рядом с часами
безопасность и маршрутизация
аварийная блокировка (kill switch) блокирует весь сетевой трафик компьютера в случае неожиданного разрыва vpn
раздельное туннелирование (bypass) российские банки, сервисы и госуслуги работают напрямую через локального провайдера
безопасный dns защита от подмены адресов и провайдерской фильтрации через ./dns
