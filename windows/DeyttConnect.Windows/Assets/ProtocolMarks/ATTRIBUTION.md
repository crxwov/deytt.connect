The original geometry is retained; fills follow the active application theme. The complete license text is in `Hysteria-MIT-LICENSE.md`.
- **AmneziaWG:** `amnezia-mark.svg` comes from <https://github.com/amnezia-vpn/amnezia-client/blob/dev/client/images/controls/amnezia.svg>. The source repository is GPL-3.0; see the repository's root `LICENSE`. The path geometry is retained and its fill follows the active application theme.
- **VLESS:** the Windows route list uses a simple V-stroke monogram matching the in-app `ProtocolLogo` drawing. No verified official protocol mark is bundled.
- **Trojan:** the Windows route list uses a simple T-stroke monogram matching the in-app `ProtocolLogo` drawing. No verified official protocol mark is bundled.
