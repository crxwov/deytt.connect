# Protocol marks

- **Hysteria 2:** `hysteria-symbol.svg` comes from the Hysteria media kit at <https://github.com/HyNetworks/hysteria/blob/master/media-kit/svg/symbol%201.svg>. Copyright 2023 Toby; MIT License. The original geometry is retained; fills follow the active application theme. The complete license text is in `Hysteria-MIT-LICENSE.md`.
- **AmneziaWG:** `amnezia-mark.svg` comes from <https://github.com/amnezia-vpn/amnezia-client/blob/dev/client/images/controls/amnezia.svg>. The source repository is GPL-3.0; see the repository's root `LICENSE`. The path geometry is retained and its fill follows the active application theme.
- **VLESS/Xray:** `vless-xray-symbol.svg` is an original ray pictogram associated with the Xray implementation used for VLESS ([upstream project](https://github.com/XTLS/Xray-core)). It is not an official Xray or VLESS logo.
- **Trojan:** `trojan-horse-symbol.svg` is an original horse pictogram based on the [upstream Trojan-GFW project's Trojan-horse concept](https://github.com/trojan-gfw/trojan). It is not an official project logo.
