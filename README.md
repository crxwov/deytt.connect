# deytt./connect

Android-клиент DEYTTT для подключения к своей подписке и выбора VPN-маршрута. Текущую ARM64-сборку, шаги установки, поддержку и изменения версии вы найдёте ниже.

## Установка и подключение

Текущая версия — **0.8.9**, Android 7.0 или новее. Опубликованный APK собран для ARM64 (`arm64-v8a`). Для использования нужен активный доступ DEYTTT.

1. Скачайте APK по ссылке выше и откройте загруженный файл. Если Android попросит разрешение, разрешите установку для выбранного браузера или файлового менеджера и вернитесь к установке.
2. Откройте приложение и войдите через Telegram. Укажите username, запросите одноразовый код и подтвердите вход. Если бот не может отправить код, откройте [бота DEYTTT](https://t.me/deyttbot) и запросите код ещё раз.
3. Приложение загрузит маршруты вашей подписки. Выберите «Авто» или нужный маршрут, нажмите подключение и подтвердите системный запрос Android на создание VPN-подключения.
4. Разрешите уведомление о работающем VPN, если Android его запросит. Отключайте VPN кнопкой в приложении.

Сборка опубликована для раннего доступа и подписана отладочным ключом. Это APK для ручной установки, не версия из Google Play. Если Android откажется обновлять установленную тестовую сборку, напишите в поддержку до её удаления: переустановка может сбросить локальные данные приложения.

## Возможности

- вход через Telegram и загрузка доступных маршрутов активной подписки;
- VLESS, Trojan, Hysteria 2 и AmneziaWG 3.1 там, где они доступны в подписке;
- автоматический выбор маршрута, отдельные регионы и маршрут Russia → Germany;
- проверка доступности, задержки и скорости маршрутов;
- встроенная проверка новых релизов GitHub с проверкой APK перед подтверждением установки.

Определение региона на карте можно включить в настройках. Оно использует IP-адрес через ipinfo.io, а не GPS. Подробнее о данных и условиях читайте в [политике конфиденциальности](https://deytt.space/info).

## Поддержка и сообщения об ошибках

По вопросам входа, подписки и подключения напишите в [бот DEYTTT](https://t.me/deyttbot). Для ошибки в приложении создайте GitHub Issue: укажите версию приложения, версию Android, модель устройства и шаги воспроизведения.

Issues публичные. Не прикладывайте username, коды входа, ссылки подписки, VPN-ключи, конфигурации, IP-адреса или снимки экрана с данными аккаунта.

Уязвимости сообщайте приватно через [форму Security Advisories](https://github.com/crxwov/deytt.connect/security/advisories/new), а не в публичном Issue. Подробности — в [политике безопасности](SECURITY.md).

## Лицензия и сборка

Код приложения распространяется по GNU GPL-3.0-or-later. Для компонентов и материалов сторонних проектов действуют собственные условия из [уведомлений о сторонних компонентах](THIRD-PARTY-NOTICES.md) и [атрибуций значков](THIRD_PARTY_NOTICES.md).

Для сборки нужны JDK 17, Android SDK 35, NDK 26.1, CMake 3.22.1 и Git submodules:

```bash
git submodule update --init --recursive
./gradlew assembleDebug
```

ARM64 APK появится в `app/build/outputs/apk/debug/app-arm64-v8a-debug.apk`.
