# Repository workflow

- Use GitHub (`crxwov/deytt.connect`) as the primary repository for source code, pull requests, and releases.
- Pull from GitHub `main` before starting work. Commit verified changes and push directly to GitHub. Use `main` by default unless the task calls for a branch.
- Gitea is paused and retained for historical access. Keep secrets and private project records out of this public repository.
- Follow [the release and signing instructions](docs/release-security.md) when publishing builds.
