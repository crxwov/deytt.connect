# Windows interface refinement

## Direction
A calm desktop connection instrument, not a dashboard. Keep the interactive route globe as the single signature. Supporting screens use precise alignment, readable hierarchy, muted surfaces and an unmistakable primary action. Retain current navigation and brand fonts; no framework replacement or feature removal.

## Tokens
- Background #080D17 / #F6F7FB; surface #111A29 / #FFFFFF; secondary #162235 / #EEF1F8.
- Text #F2F5FC / #111823; muted #B2BED1 / #46546B; accent #6378F6 / #4F63E8.
- Unbounded: restrained 28–32 page titles. Inter Tight: 15–18 body/controls. JetBrains Mono: measured values and short utility labels.
- Spacing: 4, 8, 12, 16, 24, 32, 40. Surface radius 16; controls 10; normal action minimum 48.

## Intended changes
| Before | After | Why |
|---|---|---|
| 44–56 non-home headings | 28–32 shared titles | Reduce competition with actual content |
| Wide 64 gutters | 40 desktop / 20 compact | Use desktop space without crowding |
| Whole settings rows grow on hover | Stable hover, subtle pointer press | Avoid shifting text and visual jitter |
| Fixed dark Support surfaces | Semantic theme resources | Consistent light/dark without losing drafts |
| User messages lowercased | Preserve original message case | Brand style must not alter conversation content |
| Invisible focusable traffic legend | Explicit disclosure or remove hidden tab stops | Keyboard focus must remain visible |

## Acceptance
Synthetic source-driven native and browser captures before/after; existing protocol/client/headless suites plus targeted theme/case/layout checks. Validate compact/desktop, both themes, no horizontal clipping, error/empty/loading states and keyboard actions. Live VPN, account/payment and OS screen-reader checks must not be claimed from synthetic fixtures. Current model cannot inspect images; final visual review needs image-capable session.
