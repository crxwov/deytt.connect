# Protocol marks

- Xray / VLESS: official XTLS documentation mark, https://github.com/XTLS/XTLS.github.io/blob/gh-pages-next/logo-dark.svg . Converted polygon coordinates to Android VectorDrawable without changing geometry.
- Hysteria: official project documentation mark, https://github.com/HyNetworks/hysteria-website/blob/master/docs/assets/logo.svg . Converted polygon coordinates to Android VectorDrawable; dark-theme white foreground and original amber retained.
- AmneziaWG: existing bundled Amnezia mark.
- Trojan: neutral diamond glyph. The official trojan-gfw documentation/repository has no standalone logo asset; this is an interface symbol, not an official logo.

Launcher ./c: regular Liberation Sans outlines (SIL Open Font License), matching the supplied monochrome banner reference; each glyph is spaced independently.
